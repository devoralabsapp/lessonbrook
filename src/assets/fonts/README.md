# Nunito

Nunito variable upright font, weights 200–1000. Self-hosted using next/font/local, used only by the Playful Retro theme.

Source: [Google Fonts / Nunito](https://github.com/google/fonts/tree/main/ofl/nunito). Copyright 2014 The Nunito Project Authors. Distributed under the [SIL Open Font License 1.1](OFL.txt). The font is unmodified. No browser requests to a font provider are required.
