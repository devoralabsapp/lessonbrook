- **Workspace cache**. Authenticated directory, lesson, statement, payment, summary and preference reads use a bounded 45-second server memory cache. Every request still checks session revocation and current account controls. A Firestore revision document supplies dependency-specific keys; business writes advance the affected revisions in the same transaction. The next read refills from Firestore, including after Shortcut payments, shared-link creation and scheduled lesson materialization. See `src/lib/server/workspace-cache.ts` and the architecture guide before adding another mutation. Cache storage is per warm server instance; direct Admin edits outside this contract may take up to the TTL to appear. No service, dependency or environment variable was added.

- **Smoothness and mobile reuse**. The server cache already serves mobile. The client now coalesces overlapping GETs only while pending, clears that registry around mutations, and still sends later reads to the server. Classes/Statements retain rows during revalidation of the same filter; changing filters hides the old result. Notes animate only in view while the document is visible, pivot around their pin, and use smaller hover/focus transforms. Red pushpins are shaded SVGs with metal needles and an embedded shadow. iOS/Android reuse their RAM Dashboard view and scroll position for equal validated snapshots, including theme/locale in the rendered state; sign-out and demo entry clear that memory. No persistent offline tuition cache was added.

- **Students and Classes**. Notes open by default. Names are larger and bold in both Notes and List. The name frame has a 2px border in the theme's primary color. In Notes, the name frame keeps the stronger paper color and the paper outside it is muted. The red pin, motion preferences, and underlined Edit/Archive actions remain part of the Notes design.
- **Lessons**. `/app/sessions` is the Lessons tab. Opening it from the navigation filters to this month in Vietnam time. Clear filters opens the full history, and student ledgers and explicit dashboard billing links start without a date restriction. Notes fill each complete grid row, keep the content centered, and render `No charge` as a status badge. The list supports automatic filtering, bulk completion of planned lessons and a month calendar.
- **Statements**. Uses the same directory card as Students, Classes and Lessons: the title and List/Notes buttons are in the header above the filters. List mode has compact rows separated by lines, with the amount and status on the right. Notes keep their pinned paper appearance inside the card. Opens on this month for the main tab and on all dates for direct student or status links. The date filter uses issue date, falling back to the Vietnam date of creation. `All time` restores the full history. Payment status sits beneath the amount in Notes. Cash payments and matched transfers appear in editable payment history.
- **Demo and mobile**. `/demo` reuses the workspace with fictional, tab-local data. Use it for visual reproduction. Native iOS/Android shells share the server API and load the web workspace for most ledger screens. On phones, Students/Classes use compact two-column notes. Lessons places Clear filters beside the smaller Lesson type field, with Today/This month/Select below. A web deploy updates these screens. Native Dashboard tokens cover all six palettes, text contrast, fonts, outlines, corners and offset shadows. The app version is 0.4.8 (iOS build 14; Android code 13). Native Dashboard reuse requires installing this rebuilt app; the maintainer previously chose to install later, so no physical-device installation was performed.

For note motion, start with [note-motion.ts](src/lib/note-motion.ts), `NotePin` in [record-note.tsx](src/components/record-note.tsx), and the note rules in [globals.css](src/app/globals.css). The `.record-note:has(> .record-identity)` selector confines the lighter paper treatment to student and class notes. The dark Afterhours FM theme has its own tint strengths. Statements layout lives in [list.tsx](src/features/statements/list.tsx).
